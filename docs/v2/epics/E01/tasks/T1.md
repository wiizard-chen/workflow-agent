# E01-T1 — Root npm workspace and TypeScript orchestration

## Objective
Establish the root npm-workspace and V2 TypeScript orchestration boundary without moving or changing V1 Pi resources.

## Scope
- Add root `workspaces: ["apps/*", "packages/*"]`.
- Preserve root package name, `pi` manifest, `extensions/`, `skills/`, `.pi/agents/`, `scripts/wfpi`, and V1 `tsconfig.json` behavior.
- Add `tsconfig.base.json` for strict Node 22+ ESM/NodeNext V2 configuration.
- Add `tsconfig.v2.json` with references for the five approved workspace paths.
- Add root script names required by the PRD, using placeholders only where later tasks provide implementations; T1 must not make default V1 gates falsely pass over missing V2 work.
- Update the npm lockfile consistently if root workspace metadata requires it.

## Non-goals
No workspace package source, Runtime behavior, daemon, Worker, protocol, domain model, or compatibility harness.

## Acceptance
- Root remains `pi-workflow` with unchanged Pi resource paths and manifest semantics.
- Existing V1 tests and V1 typecheck pass.
- V2 compiler configuration is isolated from the existing V1 `tsconfig.json`.
- No second package manager or lockfile is introduced.
- `git diff --check` passes.

## Task-stage gate
```bash
npm run test:v1 && npm run typecheck:v1 && git diff --check
```
