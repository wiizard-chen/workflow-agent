# E01-T3 — V2 tests, aggregate gates, and authoritative boundary validator

## Objective
Make V2 package boundaries and repository-wide quality coverage deterministic.

## Scope
- Add `node:test` smoke tests for each workspace.
- Implement `scripts/validate-v2-boundaries.mjs` as the authority for workspace manifests, allowed dependency edges, TypeScript references, package exports, undeclared internal dependencies, production→testkit prohibition, application↔application prohibition, and relative deep-import prohibition.
- Make the validator fail when npm dependencies and TypeScript references disagree.
- Implement root `test:v1`, `test:v2`, `test`, `typecheck:v1`, `typecheck:v2`, `typecheck`, `build:v2`, and `check` semantics.
- Ensure `typecheck:v2` starts from a clean V2 output state and builds referenced declarations rather than relying on stale `dist`.
- Ignore generated `dist` and TypeScript build metadata without hiding source/evidence files.

## Non-goals
No `wfpi`/Git-package install harness and no Runtime behavior.

## Acceptance
- Every V2 workspace contributes a real `node:test` smoke.
- Default `npm test` and `npm run typecheck` cover both V1 and V2.
- Boundary validator detects forbidden fixture mutations and passes the approved graph.
- Clean build/test succeeds without global test loaders or bundlers.

## Task-stage gate
```bash
npm run test:v1 && npm run test:v2 && npm run typecheck && npm run build:v2 && node scripts/validate-v2-boundaries.mjs && git diff --check
```

## Evidence
Return test counts, validator result, clean-build result, changed files, and commit SHA.
